# Desafio Departamental — Departamento de Projetos

Projeto desenvolvido como parte do Desafio Departamental do Programa Trainee, 
com o objetivo de demonstrar na prática um fluxo de trabalho seguro com Git 
e GitHub (branching, commits semânticos, Pull Requests e code review).

## 🎯 Objetivo
Simular um ambiente de desenvolvimento ágil, aplicando boas práticas de 
versionamento de código para evitar problemas comuns como sobrescrita de 
arquivos, falta de rastreabilidade e ausência de revisão antes do deploy.

## 🚀 Funcionalidades
- Página principal estruturada em HTML5
- Header com logo clicável (reinicia a página)
- Footer estilizado com texto de direitos autorais

## 🛠️ Tecnologias
- HTML5
- CSS3

## 🌿 Fluxo de Branches
- `main` → branch principal/estável
- `dev` → branch de desenvolvimento, onde as tasks são integradas
- `task/*` → branches individuais para cada funcionalidade
